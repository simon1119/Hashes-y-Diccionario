# Hashes y Diccionarios - Simón Berrio Rodas 11°6

## Descripción

Este repositorio contiene el desarrollo de una guía de aprendizaje sobre **estructuras de datos no lineales: Hashes y Diccionarios**.

En esta actividad se trabajó el concepto de diccionarios, las relaciones entre claves y valores y algunos de sus usos en programación y seguridad informática.

Los ejercicios fueron realizados en **Python, C# y Java** para comparar cómo se implementa una estructura similar en diferentes lenguajes de programación.

## Ejercicios

### Ejercicio 1 - Agenda de contactos

Se crea un diccionario que almacena el nombre de un contacto como clave y su número telefónico como valor.

El programa solicita un nombre al usuario y muestra el número de teléfono si el contacto existe.

Archivos:
- ejercicio_p01.py
- EjercicioP01.cs
- ejercicio_p01.java

### Ejercicio 2 - Frecuencia de letras

El programa recibe una frase y cuenta cuántas veces aparece cada letra, sin distinguir entre mayúsculas y minúsculas y sin contar los espacios.

Finalmente, muestra las letras ordenadas desde la que aparece más veces hasta la que aparece menos veces.

Archivos:
- ejercicio_p02.py
- EjercicioP02.cs
- ejercicio_p02.java

### Ejercicio 3 - Menú de productos

Se crea un diccionario que relaciona cada producto con su precio.

El programa permite:

- Agregar productos.
- Consultar precios.
- Actualizar precios.
- Eliminar productos.
- Salir del programa.

Archivos:
- ejercicio_p03.py
- EjercicioP03.cs
- ejercicio_p03.java

### Ejercicio 4 - Estudiantes por curso

Se tiene una lista de estudiantes con sus respectivos cursos y se construye un diccionario que agrupa a los estudiantes según el curso al que pertenecen.

Archivos:
- ejercicio_p04.py
- EjercicioP04.cs
- ejercicio_p04.java

## Lenguajes utilizados

## Requisitos

Para poder abrir y ejecutar los códigos de este repositorio es necesario tener instalados los siguientes programas:

- **Python:** necesario para ejecutar los archivos .py.
- **.NET SDK:** necesario para compilar y ejecutar los archivos .cs de C#.
- **Java JDK:** necesario para compilar y ejecutar los archivos .java.
- **Editor de código:** se recomienda utilizar Visual Studio Code, Visual Studio, IntelliJ IDEA o algún otro editor compatible con estos lenguajes.

También es necesario tener los archivos del repositorio descargados en el computador.
